Great question 👍.
In Java Stream API, intermediate operations are the operations that transform a stream into another stream. They are lazy, meaning they don’t do any work until a terminal operation (like collect, forEach, reduce) is invoked.

Let’s go step by step 👇

🔹 Intermediate Operations in Java Stream API
1. filter(Predicate)

Keeps only the elements that match a condition.

Predicate → returns true (keep element) or false (discard element).

✅ Example:

import java.util.*;
import java.util.stream.*;

public class FilterExample {
    public static void main(String[] args) {
        List<Integer> numbers = Arrays.asList(10, 15, 20, 25, 30);

        List<Integer> evenNumbers = numbers.stream()
                                           .filter(n -> n % 2 == 0)
                                           .collect(Collectors.toList());

        System.out.println(evenNumbers); // [10, 20, 30]
    }
}

2. map(Function)

Transforms each element into another object.

✅ Example:

List<String> names = Arrays.asList("john", "peter", "alice");

List<String> upperNames = names.stream()
                               .map(String::toUpperCase)
                               .collect(Collectors.toList());

System.out.println(upperNames); // [JOHN, PETER, ALICE]

3. flatMap(Function)

Flattens nested streams into a single stream.

Useful for working with List of Lists.

✅ Example:

List<List<String>> data = Arrays.asList(
    Arrays.asList("A", "B"),
    Arrays.asList("C", "D")
);

List<String> result = data.stream()
                          .flatMap(List::stream)
                          .collect(Collectors.toList());

System.out.println(result); // [A, B, C, D]

4. distinct()

Removes duplicate elements.

Uses equals() for comparison.

✅ Example:

List<Integer> nums = Arrays.asList(1, 2, 2, 3, 4, 4, 5);

List<Integer> unique = nums.stream()
                           .distinct()
                           .collect(Collectors.toList());

System.out.println(unique); // [1, 2, 3, 4, 5]

5. sorted() / sorted(Comparator)

Sorts elements in natural order or using a custom comparator.

✅ Example:

List<String> words = Arrays.asList("banana", "apple", "cherry");

List<String> sortedWords = words.stream()
                                .sorted()
                                .collect(Collectors.toList());

System.out.println(sortedWords); // [apple, banana, cherry]

// Custom comparator
List<String> reverse = words.stream()
                            .sorted(Comparator.reverseOrder())
                            .collect(Collectors.toList());

System.out.println(reverse); // [cherry, banana, apple]

6. peek(Consumer)

Used for debugging/logging.

It performs an action without modifying the stream.

✅ Example:

List<Integer> numbers = Arrays.asList(1, 2, 3, 4);

List<Integer> result = numbers.stream()
                              .peek(n -> System.out.println("Processing: " + n))
                              .map(n -> n * n)
                              .collect(Collectors.toList());

System.out.println(result); // [1, 4, 9, 16]

7. limit(long maxSize)

Reduces the size of the stream to at most maxSize.

✅ Example:

List<Integer> numbers = Arrays.asList(10, 20, 30, 40, 50);

List<Integer> limited = numbers.stream()
                               .limit(3)
                               .collect(Collectors.toList());

System.out.println(limited); // [10, 20, 30]

8. skip(long n)

Skips the first n elements.

✅ Example:

List<Integer> numbers = Arrays.asList(10, 20, 30, 40, 50);

List<Integer> skipped = numbers.stream()
                               .skip(2)
                               .collect(Collectors.toList());

System.out.println(skipped); // [30, 40, 50]

9. mapToInt / mapToDouble / mapToLong

Converts object stream to a primitive stream for better performance.

✅ Example:

List<String> numbers = Arrays.asList("1", "2", "3");

int sum = numbers.stream()
                 .mapToInt(Integer::parseInt)
                 .sum();

System.out.println(sum); // 6

10. boxed()

Converts primitive streams back to object streams.

✅ Example:

IntStream intStream = IntStream.range(1, 5);

List<Integer> boxed = intStream.boxed()
                               .collect(Collectors.toList());

System.out.println(boxed); // [1, 2, 3, 4]

11. takeWhile / dropWhile (Java 9+)

takeWhile: Take elements until condition is false.

dropWhile: Drop elements until condition is false, then keep the rest.

✅ Example:

List<Integer> nums = Arrays.asList(1, 2, 3, 4, 5, 1, 2);

List<Integer> taken = nums.stream()
                          .takeWhile(n -> n < 4)
                          .collect(Collectors.toList());

System.out.println(taken); // [1, 2, 3]

List<Integer> dropped = nums.stream()
                            .dropWhile(n -> n < 4)
                            .collect(Collectors.toList());

System.out.println(dropped); // [4, 5, 1, 2]

🔑 Key Points

Intermediate ops are lazy → they only run when a terminal operation is called.

They return a Stream (except special ones like mapToInt which return primitive streams).

They can be chained together.

Here are some common questions around filter():

🔸 1. What is the argument type of filter()?

Answer:
It takes a Predicate<? super T>. A predicate is a functional interface representing a condition that returns a boolean.

🔸 2. Difference between map() and filter()?

Answer:

filter() → selects elements based on a condition (boolean).

map() → transforms each element into another object.

Example:

// filter
List<Integer> even = nums.stream().filter(n -> n % 2 == 0).toList();

// map
List<String> squares = nums.stream().map(n -> "Square: " + (n*n)).toList();

🔸 3. Can we use multiple filters in a stream?

Answer:
Yes, filters can be chained:

List<Integer> result = nums.stream()
                           .filter(n -> n > 10)
                           .filter(n -> n % 2 == 0)
                           .toList();

🔸 4. What happens if filter condition always returns false?

Answer:
The resulting stream will be empty, because no elements match.

🔸 5. What happens internally when we use filter()?

Answer:

It creates a new lazy intermediate stream.

No filtering happens immediately.

Actual filtering is executed only when a terminal operation (like collect, forEach) is invoked.

🔸 6. Can we use filter() with parallel streams?

Answer:
Yes. Example:

nums.parallelStream()
    .filter(n -> n > 50)
    .forEach(System.out::println);


But interviewer may ask: is filter thread-safe?

filter() itself is stateless → safe to use in parallel streams.

But if your predicate modifies shared state → NOT safe.

🔸 7. Real-world scenario question:

Suppose you have a List<Employee> with id, name, and salary. How will you get employees with salary > 50,000?

                                   .filter(emp -> emp.getSalary() > 50000)
                                   .collect(Collectors.toList());

🔸 8. What if you pass null to filter()?

Answer:
You’ll get a NullPointerException because Predicate cannot be null.

🔹 map() in Stream API
Definition
<R> Stream<R> map(Function<? super T, ? extends R> mapper)


map() is an intermediate operation in Java Stream API.

It is used to transform each element of the stream into another object (can be same type or different type).

It returns a new Stream consisting of the transformed elements.

🔹 What Argument Does map() Take?

map() takes a Function as its argument.

Function<T, R> is a functional interface in java.util.function.

@FunctionalInterface
public interface Function<T, R> {
    R apply(T t);
}


👉 Meaning:

Input: T (element type of the stream)

Output: R (new type after transformation)

🔹 Why Do We Use map()?

We use map() when we want to:

Transform data (e.g., lowercase → uppercase, Celsius → Fahrenheit, object → property).

Extract specific fields from objects (e.g., from Employee → only names).

Apply calculations (e.g., square of numbers).

🔹 Examples
✅ 1. Square Numbers
List<Integer> numbers = Arrays.asList(1, 2, 3, 4);

List<Integer> squares = numbers.stream()
                               .map(n -> n * n)   // Function<Integer,Integer>
                               .collect(Collectors.toList());

System.out.println(squares); // [1, 4, 9, 16]

✅ 2. Convert Strings to Uppercase
List<String> names = Arrays.asList("john", "alice", "bob");

List<String> upper = names.stream()
                          .map(String::toUpperCase) // Function<String,String>
                          .collect(Collectors.toList());

System.out.println(upper); // [JOHN, ALICE, BOB]

✅ 3. Extract a Field from Objects
class Employee {
    String name;
    int salary;
    Employee(String name, int salary) { this.name = name; this.salary = salary; }
    public String getName() { return name; }
}

List<Employee> employees = Arrays.asList(
    new Employee("Alice", 50000),
    new Employee("Bob", 60000)
);

List<String> namesOnly = employees.stream()
                                  .map(Employee::getName)  // Function<Employee,String>
                                  .collect(Collectors.toList());

System.out.println(namesOnly); // [Alice, Bob]

✅ 4. Convert Object Type
List<String> nums = Arrays.asList("1", "2", "3");

                            .collect(Collectors.toList());

🔹 What is Comparator?

Comparator<T> is a functional interface in java.util.

It defines a custom ordering for objects.

It is mainly used in sorting (e.g., with Stream.sorted(), Collections.sort()).

🔹 Definition
@FunctionalInterface
public interface Comparator<T> {
    int compare(T o1, T o2);
}


👉 The compare(o1, o2) method:

Returns negative → if o1 should come before o2.

Returns zero → if o1 and o2 are equal in sorting.

Returns positive → if o1 should come after o2.

🔹 Why Do We Use Comparator?

To sort custom objects (like Employee by salary, Student by grade).

To control ordering (ascending, descending, multiple fields).

Works with Stream API (sorted(Comparator)), Collections.sort(), PriorityQueue, etc.

🔹 Common Ways to Use Comparator

Java provides several static helper methods in Comparator (Java 8+).

Comparator.comparing(Function) → compares by a field.

Comparator.comparingInt(ToIntFunction) → compares by int field.

Comparator.comparingDouble(ToDoubleFunction) → compares by double field.

Comparator.naturalOrder() → natural order.

Comparator.reverseOrder() → reverse order.

thenComparing(...) → for multi-level sorting.

Comparator.nullsFirst(...) / Comparator.nullsLast(...) → handle null values.

public class SecondLargest {
    public static void main(String[] args) {
        List<Employee> employees = Arrays.asList(
            new Employee("Alice", 50000),
            new Employee("Bob", 70000),
            new Employee("Charlie", 60000),
            new Employee("David", 70000) // duplicate salary
        );

        // Find the second largest salary
        Optional<Integer> secondLargestSalary = employees.stream()
            .map(Employee::getSalary)                  // extract salaries
            .distinct()                                // remove duplicates
            .sorted(Comparator.reverseOrder())         // sort descending
            .skip(1)                                   // skip first (largest)
            .findFirst();                              // get second largest

        if (secondLargestSalary.isPresent()) {
            System.out.println("Second largest salary: " + secondLargestSalary.get());
        } else {
            System.out.println("No second largest salary found.");
        }
    }
}

.map(Employee::getSalary) → extract only salaries.

.distinct() → ensure duplicates don’t affect result.

.sorted(Comparator.reverseOrder()) → descending order.

.skip(1) → skip the largest.

.findFirst() → pick the next one.

🚀 Terminal Operations in Stream API

Terminal operations produce a result or a side-effect and close the stream (cannot reuse it).
They trigger the processing of the pipeline built with intermediate operations.

✅ 1. forEach()

👉 Performs an action for each element. (Used for side effects)

List<String> names = List.of("Alice", "Bob", "Charlie");

names.stream()
     .forEach(n -> System.out.println("Hello " + n));


📌 Use Case: Printing, logging.
⚠️ Note: Doesn’t guarantee order if used on parallel streams (use forEachOrdered).

✅ 2. toArray()

👉 Collects elements into an array.

String[] arr = names.stream().toArray(String[]::new);
System.out.println(Arrays.toString(arr)); // [Alice, Bob, Charlie]

✅ 3. reduce()

👉 Performs a reduction (fold) on the elements to produce a single result.

int sum = List.of(1, 2, 3, 4, 5)
              .stream()
              .reduce(0, (a, b) -> a + b);

System.out.println(sum); // 15


📌 Use Case: Sum, max, product, string concatenation.

✅ 4. collect()

👉 Collects elements into a collection or other container.

List<String> upper = names.stream()
                          .map(String::toUpperCase)
                          .collect(Collectors.toList());

System.out.println(upper); // [ALICE, BOB, CHARLIE]


📌 Most powerful terminal op → supports Collectors.groupingBy, partitioningBy, joining, etc.

✅ 5. min() / max()

👉 Returns the minimum or maximum element based on comparator.

Optional<Integer> minVal = List.of(10, 5, 20).stream().min(Integer::compareTo);
System.out.println(minVal.get()); // 5

Optional<Integer> maxVal = List.of(10, 5, 20).stream().max(Integer::compareTo);
System.out.println(maxVal.get()); // 20

✅ 6. count()

👉 Returns the number of elements.

long count = names.stream().count();
System.out.println(count); // 3

✅ 7. anyMatch(), allMatch(), noneMatch()

👉 Returns boolean result based on predicate condition.

List<Integer> nums = List.of(2, 4, 6, 8);

System.out.println(nums.stream().allMatch(n -> n % 2 == 0)); // true
System.out.println(nums.stream().anyMatch(n -> n > 5)); // true
System.out.println(nums.stream().noneMatch(n -> n < 0)); // true


📌 Use Case: Validations.

✅ 8. findFirst() / findAny()

👉 Returns an element wrapped in Optional.

Optional<String> first = names.stream().findFirst();
System.out.println(first.get()); // Alice

Optional<String> any = names.parallelStream().findAny();
System.out.println(any.get()); // Could be Alice/Bob/Charlie


📌 findFirst() → deterministic.
📌 findAny() → useful in parallel streams for performance.

✅ 9. iterator() / spliterator() (less common)

👉 Converts stream into an iterator.

Iterator<String> it = names.stream().iterator();
while (it.hasNext()) {
    System.out.println(it.next());
}


📌 Rarely used → mostly replaced by forEach.

allMatch()	boolean	All elements match condition
